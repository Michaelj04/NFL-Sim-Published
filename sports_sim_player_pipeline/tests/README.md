# Tests

Tests are final-phase work in V11.6.4.

Do not spend early implementation time creating or running broad test suites. Build the player pipeline, validators, scheduler, and debug exports first.

After core implementation is complete, use this folder for:

- CSV parser and validator tests
- validator failure-case tests
- deterministic RNG tests
- recruit generation tests
- position conversion tests
- recruiting and roster tests
- development tests
- injury, production, morale, and promise tests
- transfer portal tests
- draft bridge and NFL import tests
- seeded snapshot tests
- long-run balance tests
- performance benchmark tests

If the user stops the task before final tests, document tests as deferred in the self-audit.
